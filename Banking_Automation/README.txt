Banking Automation System
=========================
A simple console-based banking application written in Python.

Requirements: Python 3.6 or newer (no external libraries needed)

How to run:
    python banking_automation.py

Features:
    - Create account with 4-digit PIN
    - Login / Logout
    - Deposit, Withdraw, Transfer
    - Balance enquiry
    - Mini statement
    - Change PIN
    - Data saved in bank_data.json (created automatically)
